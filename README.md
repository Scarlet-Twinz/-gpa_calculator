# Academix Pro — GPA Calculator

A lightweight browser-based university GPA calculator built around a 5.0 grading scale.

## Features

- Add multiple courses dynamically
- Enter course codes and credit units
- Select grades from A–F on a 5.0 scale
- Calculate the weighted GPA from course units and grade points
- Display the result to two decimal places

## Grading Scale

| Grade | Point |
| --- | ---: |
| A | 5 |
| B | 4 |
| C | 3 |
| D | 2 |
| E | 1 |
| F | 0 |

## Technologies

- HTML
- CSS
- JavaScript

## How the Calculation Works

For each course, the application multiplies the course units by the selected grade point. It then divides the total quality points by the total registered units to produce the GPA.

## Run Locally

No build tools or dependencies are required.

1. Clone the repository.
2. Open `index.html` in a modern web browser.
3. Add your courses and units, select the corresponding grades, and choose **Calculate GPA**.
